# Datasets

Your datasets go here, one folder each. This repo ships none: upstream
deploys nothing. See [start_repo.md](../doc/procedures/start_repo.md).

To start from an example, copy it from [examples/](../examples/), without
its **genie.yml**. Add that after the first load, with
[add_genie.md](../doc/procedures/add_genie.md).

```
cp -r examples/edsm datasets/
rm datasets/edsm/genie.yml
```
