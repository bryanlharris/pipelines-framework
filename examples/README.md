# Examples

Finished datasets to learn from and copy. Nothing here deploys: the bundle
reads only **datasets/**. Copy one into datasets/ to deploy it.

- **edsm**: several tables, gzipped files, and a gold layer of SQL tables
- **treasury**: one table, the daily yield curve
- **fred**: one table, the federal funds rate
- **fdic**: one table, bank quarterly financials, with fail rules
- **documents**: fake PDFs, labeled for PII with ai_classify
